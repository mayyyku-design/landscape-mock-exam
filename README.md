# 景觀高考模擬考

113–115 年高考三級與地方特考三等景觀類科的原卷資料與計時練習網站。

## GitHub Pages 發布

將本資料夾內容上傳至 GitHub 儲存庫。在儲存庫的 Settings → Pages，選擇 Deploy from a branch，分支 main、目錄 /docs，儲存即可。

所有網頁資產使用相對路徑，可直接放在 GitHub Pages 專案網站。

## 資料與練習模式

- docs/papers 包含依年度與考試類型整理的 40 份 PDF。
- 專業科目顯示自編練習提示，可計時並輸入作答內容；提示並非各年度原卷逐題轉錄，也無官方申論評分。
- 共同科目的選擇題介面目前只有示範題目與示範選項，尚未匯入實際考題或自動批改。實際試題及官方答案請開啟 papers 中對應 PDF。
- 作答內容尚未儲存；關閉練習視窗或重新整理會清除。

## 官方資料來源

[考選部考畢試題查詢平台](https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx)

- docs/papers：試題與答案 PDF。
